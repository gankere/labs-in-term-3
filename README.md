## Bayan — Duplicate File Finder

Утилита для поиска файлов-дубликатов по содержимому. Реализована постраничная (блочная) проверка файлов с использованием хеш-функции CRC32.

## Особенности:
1) Чтение блоками – Файлы читаются блоками заданного размера S (параметр --block-size). Последний неполный блок дополняется нулями до размера S.
2) Кэширование блоков – Каждый блок читается с диска максимум один раз благодаря FileBlockReader, который хранит прочитанные блоки в памяти для повторного использования.
3) Алгоритм хеширования – Поддерживается crc32 (используется по умолчанию) и md5. Реализация через Boost.CRC.
4) Фильтрация по маскам – Маски имён файлов (например, *.txt, *.jpg) применяются без учёта регистра. Реализация интерпретирует маски как подстроки в имени файла.

## Требования для сборки

- **CMake** версии 3.10 или выше
- **Компилятор C++17** (g++ ≥ 7, clang ≥ 5, MSVC ≥ 2017)
- **Boost** библиотеки (модули filesystem и program_options)
- **Ninja** (рекомендуется для быстрой сборки)

## Сборка (PowerShell) (из корня репозитория)
mkdir build
cd build
cmake .. -G Ninja
ninja

## Использование
./bayan [ОПЦИИ] <директории...>
--help      показать подсказку
--dirs <paths...>     директории для сканирования (обяз.)
--exclude <paths...>        исключённые директории
--depth <int>             уровень рекурсии (0 = без рекурсии, -1 = без ограничений), по умолчанию -1
--min-size<uint64>           минимальный размер файла в байтах (по умолчанию 1)
--mask <masks...>        маски имён файлов
--block-size <size_t>         размер блока S (по умолчанию 512)
--hash <crc32|md5>            алгоритм хеширования (по умолчанию crc32)
